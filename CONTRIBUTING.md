# Contributing

Thanks for contributing to Nexus AI Client.

## Development

- Keep changes focused and readable.
- Follow existing Kotlin and Jetpack Compose conventions.
- Do not commit API keys, passwords, or other secrets.
- Add or update tests when changing behavior.
- Use clear commit messages.

## Pull requests

Explain what changed, why it changed, and how you tested it. Small, focused pull requests are easier to review.
